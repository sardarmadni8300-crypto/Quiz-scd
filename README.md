# My First Web Page

## Project Overview

This project is a simple HTML-based web page created to demonstrate the basic structure and elements of an HTML document.

The webpage contains a heading, paragraph, and a clickable hyperlink.

## Features

- Displays a welcome heading.
- Contains a basic paragraph.
- Includes a clickable external link.
- Uses a simple and clean HTML structure.
- Responsive viewport settings are included.

## Technologies Used

- HTML5
